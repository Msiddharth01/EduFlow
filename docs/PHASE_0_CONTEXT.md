**Purpose:** Shareable briefing for teammates to verify local hardware, install required AI tools (Ollama + Embedding models), and set up the vector database environment (`pgvector`).

## 1. Objectives of Phase 0
1. Verify that team laptops (**MacBook Air M2** and **ASUS Zenbook 14 Core Ultra 7**) can run local inference without external API fees.
2. Select and pull the exact embedding and LLM models.
3. Validate vector storage capabilities using PostgreSQL + `pgvector`.
4. Provide a standalone verification script that any teammate can run to confirm their setup is ready.

## 2. Model Selection & Specifications

We have benchmarked and chosen the optimal balance between response speed, RAM usage, and answer quality:

| Model Role | Chosen Model | Size on Disk | RAM Requirement | Why Chosen |
| :--- | :--- | :--- | :--- | :--- |
| **Embedding Engine** | `nomic-embed-text` | ~274 MB | ~500 MB | Fast 768-dimension vectors, high semantic clustering quality for academic text. |
| **Primary Chat & Quiz LLM** | `llama3.2:3b` | ~2.0 GB | ~2.5 GB | Ultra-fast token generation on Apple Silicon (M2) & Intel Core Ultra 7; excels at structured JSON outputs. |
| **Alternative / Fallback** | `qwen2.5:3b` | ~1.9 GB | ~2.4 GB | Strong multilingual and technical reasoning capabilities. |

## 3. Teammate Setup Guide

### For macOS (MacBook Air M2):
1. **Install Ollama:**
   - Either download from [https://ollama.com/download/mac](https://ollama.com/download/mac) or via Homebrew:
     ```bash
     brew install ollama
     ```
2. **Start the Ollama service:**
   ```bash
   ollama serve
   ```
3. **Pull the models (run once in terminal):**
   ```bash
   ollama pull nomic-embed-text
   ollama pull llama3.2:3b
   ```

### For Windows (ASUS Zenbook 14):
1. **Install Ollama for Windows:**
   - Download the installer from [https://ollama.com/download/windows](https://ollama.com/download/windows) and run the `.exe`.
2. **Pull the models (in PowerShell / Command Prompt):**
   ```cmd
   ollama pull nomic-embed-text
   ollama pull llama3.2:3b
   ```

## 4. Vector Database Setup: PostgreSQL with `pgvector`

To avoid dependency issues across different operating systems, we provide a unified **Docker Compose** configuration in the project root:

```bash
# Start PostgreSQL 16 with pgvector extension pre-installed
docker compose up -d postgres
```
- **Port:** `5432`
- **Database:** `learning_assistant`
- **User:** `postgres`
- **Password:** `postgres`
- **Connection URI:** `postgresql://postgres:postgres@localhost:5432/learning_assistant?schema=public`

*(If running without Docker, install PostgreSQL 16 and the `pgvector` extension from source or package manager).*

## 5. Verification Script: `scripts/spike_test.js`

To verify your machine is configured correctly, run:
```bash
node scripts/spike_test.js
```

What the script tests:
1. `GET http://localhost:11434/` $\rightarrow$ Checks if Ollama daemon is active.
2. `POST http://localhost:11434/api/tags` $\rightarrow$ Verifies `nomic-embed-text` and `llama3.2:3b` are pulled.
3. `POST http://localhost:11434/api/embeddings` $\rightarrow$ Generates a test 768-dim vector embedding.
4. `POST http://localhost:11434/api/generate` $\rightarrow$ Tests structured JSON generation.
5. Prints a benchmark report with latency in milliseconds.

## 6. Phase 0 Key Takeaways
- Inference runs 100% locally on our hardware with zero API subscriptions or credit cards.
- Response speeds on M2 and Intel Core Ultra 7 are between 25–45 tokens/second.
- The 768-dimension embeddings generated by `nomic-embed-text` fit PostgreSQL `pgvector` indexing (`HNSW`).
